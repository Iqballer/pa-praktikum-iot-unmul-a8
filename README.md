## Deskripsi
Sistem Smart Garage yaitu adalah sebuah garasi pintar yang dimana pengguna dapat memonitoring suhu ruang garasi menggunakan sensor DHT22 dan mengkontrol pintu garasi secara otomatis dengan menggunakan IoT, dalam sistem ini terdapat juga sensor Ultrasonik dan Buzzer untuk menjaga jarak antara kendaraan dengan tembok saat ingin memakirkan kendaraan ke dalam garasi. Sistem ini dapat dimonitoring secara real time melalui platfrom Kodular dan Telegram Bot, di dalam kodular terdapat informasi mengenai suhu garasi, jarak kendaraan, di kodular ini juga dapat mengkontrol pintu garasi tanpa harus membuka pintu garasi secara manual. Lalu pada Telegram Bot berfungsi untuk memberikan peringatan jika suhu garasi berada di batas yang tidak normal dan memberikan peringatan juga saat kendaraan terlalu dekat dengan tembok.
